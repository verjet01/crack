常见问题

如何使用激活码？ ▼

1. 打开 JetBrains IDE

2. 点击 Help → Edit Custom VM Options

3. 添加: -javaagent:/path/to/ja-netfilter.jar

4. 重启 IDE

5. 点击 Help → Manage Subscriptions

6. 粘贴激活码

激活码有效期是多久？ ▼

默认有效期到 2099 年 12 月 31 日，可以在生成时自定义。

支持哪些 IDE？ ▼

支持 JetBrains 全家桶：IntelliJ IDEA、PyCharm、PhpStorm、GoLand、WebStorm、CLion、Rider、DataGrip、RubyMine、AppCode、DataSpell、RustRover。

为什么提示 Key is invalid？ ▼

请确保：

1. ja-netfilter.jar 路径正确

2. 已重启 IDE

3. 之前使用过其它激活工具的，先取消激活
